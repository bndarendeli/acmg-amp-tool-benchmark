# Figure 2: Comprehensive Variant Classification Tool Performance Analysis

This directory contains all scripts and data files needed to generate Figure 2 - a comprehensive 3-panel analysis of variant classification tool performance.

## Output Figure
- **Figure**: `Figure2_Comprehensive.png` / `Figure2_Comprehensive.pdf`
- **Location**: `../../analysis_last/figures/`

## Figure Description

**Figure 2** is a comprehensive 3-panel figure showing:

### Panel A (Left): Call Rate Spectrum Across Evaluation Cohorts
- Horizontal stacked bar chart showing call rates for 14 tools
- Four evaluation cohorts: ClinGen, HGMD+ClinVar HL, FOXL2, HGMD+ClinVar Cancer
- Shows percentage of variants successfully classified by each tool

### Panel B (Top Right): Ground Truth of Unresolved Variants (Unknown + NULL)
- Stacked bar chart showing distribution of unresolved variants
- Categories: Unknown, NULL/Not_VUS, VUS, LB, B, LP, P
- Compares tools: Exomiser, InterVar_2018, Franklin, InterVar_2025, DiabloACMG, AutoGVP

### Panel C (Bottom Right): InterVar 2018 vs 2025 vs Ground Truth
- Grouped bar chart comparing classification distributions
- Shows how InterVar versions (2018 vs 2025) compare to ground truth
- Categories: P, LP, VUS, LB, B, Unk (Unknown)

## How to Run

### Quick Start (Using Pre-generated Data)
```bash

```

3. **Generate the figure:**
```bash
python3 create_figure2_comprehensive.py
```

**Note**: Step 1 requires ground truth files and tool result files to be available.

## Technical Details

### Panel A Data Source
- Uses pre-calculated call rates from `corrected_call_rates.csv`
- Call rate = (Number of classified variants / Total variants) × 100
- Excludes NULL/empty classifications

### Panel B Calculation
- Analyzes variants where tools returned "Unknown" or NULL
- For each unresolved variant, checks ground truth classification
- Shows distribution: P, LP, VUS, LB, B, Unknown, NULL/Not_VUS

### Panel C Calculation
- Compares InterVar_2018 vs InterVar_2025 classifications
- Shows classification distribution for both versions
- Includes ground truth for comparison
- Categories: P (Pathogenic), LP (Likely Pathogenic), VUS, LB (Likely Benign), B (Benign), Unk (Unknown)
